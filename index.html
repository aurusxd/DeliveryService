Delivery Service API

Интерактивная спецификация методов для WPF DeliveryService

Методы заказов (OrderService)

GET /api/orders
Соответствует методу: OrderService.GetAllAsync(). Возвращает список всех заказов из базы данных.
Пример успешного ответа (JSON): 
[
  {
    "id": 1,
    "clientName": "Иван Иванов",
    "route": "ул. Ленина -> ул. Пушкина",
    "status": "Новый",
    "price": 450.00,
    "orderTime": "2026-06-10T02:00:00Z",
    "courierId": null
  }
]
POST /api/orders
Соответствует методу: OrderService.CreateOrderAsync(client, order). Создает новый заказ со статусом "Новый".
Тело запроса (Request Body):
{
  "clientName": "Петр Петров",
  "addressFrom": "ул. Сибирская, д. 12",
  "addressTo": "ул. Красная, д. 5",
  "price": 320.00
}
Варианты ответов:
  • 200 OK Заказ успешно создан и привязан к клиенту.
  • 400 Bad Request Ошибка: пустые адреса или отсутствует имя клиента.
PUT /api/orders/{id}/status
Соответствует методу: OrderService.ChangeStatusAsync(id, status, feedback). Обновляет статус и записывает действие в историю.
Тело запроса (Request Body):
{
  "newStatus": "Доставлен",
  "feedback": "Все приехало горячим, спасибо!"
}

Методы курьеров (CourierService)

GET /api/couriers
Соответствует методам: CourierService.GetAllAsync(), GetActiveCouriersAsync() и GetFreeCouriersAsync(). Позволяет получить список курьеров с фильтрацией.
Параметры запроса (Query URL):
  • status (опционально) — варианты: all (все), active (активные), free (свободные)
Пример ответа: 
[
  { "id": 1, "name": "Курьер Алексей" },
  { "id": 2, "name": "Курьер Дмитрий" }
]
